# BridgeMinds Lab — Elegant Static Website

A responsive, multi-page HTML/CSS/JS website using the supplied BridgeMinds Lab logo, photos, and existing website content.

## Files
- `index.html` — homepage
- `services.html` — services and prices
- `process.html` — approach
- `stories.html` — student stories placeholder
- `contact.html` — contact details and consultation form
- `css/style.css` — shared responsive styling
- `js/main.js` — mobile navigation toggle
- `images/` — supplied logo and photographs

## Deploy to GitHub + Vercel
1. Extract this ZIP.
2. Upload all files and folders to the root of your GitHub repository.
3. In Vercel, import the repository. Set Framework Preset to **Other**.
4. Leave Root Directory blank (repository root); no build command or output directory is needed for this static HTML site.
5. Deploy.

The Google Fonts import requires an internet connection; system font fallbacks are included. The consultation form and social links point to the URLs supplied for BridgeMinds Lab.


Homepage includes the consultant profile for Vaishali Srivastava and her portrait in `images/vaishali-srivastava.png`.
